Siapkan · sekitar tiga menit

Pasang plugin dalam empat langkah

Satu file membawa semuanya: 26 skill dan konektor SOMIN yang mereka gunakan untuk membaca data Anda. Anda memerlukan Claude (aplikasi desktop atau claude.ai) dan akun SOMIN; Figma dan Postly bersifat opsional.

  1. 1

    Masuk: SOMIN dulu, lalu Claude

    Masuk di cloud.somin.ai dengan akun yang workspace-nya harus dapat dilihat Claude. Lalu buka claude.ai atau aplikasi desktop Claude.

    Aturan emas: Claude terhubung ke akun SOMIN mana pun yang sedang masuk saat Anda mengeklik Connect, jadi SOMIN selalu didahulukan.

  2. 2

    Unggah plugin

    Buka Customize › Plugins ↗

    Klik Add › Upload plugin dan pilih marketing-mondays.plugin dari folder Downloads Anda. Plugin akan muncul di daftar plugin Anda dalam keadaan aktif. Tidak ada pustaka skill terpisah yang perlu diunduh: plugin ini sudah memuat ke-26 skill.

    Belum mengunduhnya? Dapatkan plugin terlebih dahulu.

  3. 3

    Hubungkan SOMIN dari halaman plugin

    Mengunggah plugin tidak membuat Anda masuk ke layanan apa pun. Buka Marketing Mondays di Customize › Plugins dan pilih tab Connectors. SOMIN menampilkan salah satu dari tiga status:

    • Not added: klik Add, lalu Connect.
    • Not connected: klik Connect.
    • Connected: selesai.

    Connect langsung menautkan akun SOMIN yang sedang Anda gunakan; tidak ada layar persetujuan tambahan. Pada paket Team atau Enterprise, jika Anda tidak bisa menambahkannya sendiri, minta Owner Claude Anda untuk menambahkan konektor SOMIN, lalu hubungkan dengan akun Anda sendiri.

  4. 4

    Pastikan berfungsi, lalu jalankan deck pertama Anda

    Tanyakan kepada Claude workspace SOMIN mana saja yang dapat dilihatnya ↗. Jika daftar nama workspace muncul dalam beberapa detik, berarti Anda sudah terhubung.

    Lalu coba alur kerja lengkapnya. Buka Claude dengan prompt ini yang sudah terisi ↗, pilih workspace dan brand saat Claude bertanya, lalu saksikan Claude menyusun deck-nya:

    SOMIN MCP saya sudah terhubung. Berikan daftar workspace yang bisa saya gunakan; setelah saya memilih, berikan daftar brand yang tersedia di workspace tersebut; setelah saya memilih brand, buat deck strategi 12 bulan untuk brand yang saya pilih. Gunakan /somin-brand-deck untuk analisis lengkap dan /somin-brand-guideline untuk gaya SOMIN. Mulai dengan /scope-elicitation.

    Anda juga bisa mengetik / di kotak pesan: menunya menampilkan setiap skill beserta plugin asalnya.

Tidak ada tab Connectors, atau SOMIN tidak mau terhubung dari sana? Tambahkan SOMIN sebagai konektor kustom

Gunakan cara ini sebagai pengganti langkah 3, bukan sebagai tambahan: dua koneksi SOMIN membuat Claude mendapatkan alat yang sama dua kali.

Buka dialog “Add custom connector” yang sudah terisi ↗

Atau secara manual: di Claude, buka Customize › Connectors › Add custom connector. Isi dua kolom, biarkan kolom OAuth di bawah Advanced settings kosong, lalu klik Add. Kemudian klik Connect pada entri SOMIN berlabel CUSTOM.

NamaSOMIN
URL serverhttps://cloud.somin.ai/_mcpPertahankan garis bawahnya: /_mcp, bukan /mcp.

Pemberitahuan merah muda “suggested by an external link” memang normal saat memakai tautan yang sudah terisi. Periksa nama dan URL, lalu klik Add.

Mengalami kendala?

  • Tidak ada opsi “Upload plugin”: organisasi Anda mengatur plugin mana yang boleh ditambahkan anggota. Minta Owner Claude Anda untuk mengizinkannya, atau untuk menambahkan plugin itu bagi Anda.
  • SOMIN menampilkan “Not added” dan Anda tidak bisa menambahkannya: pada paket Team dan Enterprise, konektor ditambahkan oleh Owner. Mintalah kepada mereka, atau gunakan cara konektor kustom di atas.
  • Terhubung ke akun SOMIN yang salah: keluar lalu masuk kembali di cloud.somin.ai, kemudian putuskan dan hubungkan ulang SOMIN dari tab Connectors pada plugin.
  • Claude tidak menggunakan skill-nya: buka plugin di Customize › Plugins dan pastikan tombolnya dalam posisi aktif.

Detail lebih lanjut tentang koneksi SOMIN: panduan koneksi Claude ↗ dari SOMIN (lewati langkah pustaka skill-nya: plugin ini sudah berisi skill tersebut). Pertanyaan: ask@mondays.marketing.

Di Claude Code: plugin yang ditambahkan di aplikasi Claude akan tersinkron ke Claude Code yang masuk dengan akun yang sama; jalankan /reload-plugins. Atau jalankan claude --plugin-dir ./marketing-mondays.zip untuk satu sesi. Lalu jalankan /mcp, pilih SOMIN, dan masuk. Skill muncul sebagai /marketing-mondays:<skill>.

FAQ

Pertanyaan yang sering diajukan

Apa itu plugin Marketing Mondays?

Plugin gratis untuk Claude yang mengemas alur kerja pemasaran agentik yang diperagakan di Marketing Mondays pada 12 Oktober 2026. Delapan skill utama dan 18 skill pendukungnya memantau pasar Anda, mengurai audiens dan pesaing, menentukan whitespace, membuat brief, deck, dan materi kreatif, serta merilis kalender konten, semuanya dari data SOMIN Anda.

Apa yang saya perlukan untuk menggunakannya?

Claude dengan dukungan plugin: aplikasi desktop Claude, claude.ai, atau Claude Code. Anda juga memerlukan akun SOMIN, karena setiap skill membaca data Anda sendiri melalui konektor SOMIN. Konektor Figma dan Postly bersifat opsional, untuk langkah buat dan rilis.

Apakah ada biayanya?

Plugin ini gratis diunduh. Plugin berjalan di dalam paket Claude Anda sendiri dan di akun SOMIN Anda sendiri.

Bisakah saya menggunakannya di Claude Code?

Bisa. Pasang di aplikasi Claude lalu jalankan /reload-plugins di Claude Code yang masuk dengan akun yang sama, atau jalankan claude --plugin-dir dengan file .zip yang sudah diunduh untuk satu sesi. Skill muncul sebagai /marketing-mondays:<skill>.

Ke mana data saya dikirim?

Skill membaca dari workspace SOMIN Anda lalu menyerahkan laporan, deck, dan draf kembali kepada Anda. Contoh di dalam skill bersifat fiktif, sehingga hasil Anda hanya menggunakan data Anda. Data yang Anda isi di formulir unduhan dikirim ke SOMIN, mitra teknologi Marketing Mondays.
