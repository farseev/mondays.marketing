設定 · 約三分鐘

四個步驟安裝外掛程式

一個檔案就包含所有內容：26 項技能，以及讓技能讀取您數據的 SOMIN 連接器。您需要 Claude（桌面應用程式或 claude.ai）與 SOMIN 帳號；Figma 與 Postly 為選用。

  1. 1

    登入：先 SOMIN，再 Claude

    請在 cloud.somin.ai 以您希望 Claude 能看到其工作區的帳號登入。接著開啟 claude.ai 或 Claude 桌面應用程式。

    黃金法則：Claude 會連結到您點擊 Connect 時已登入的 SOMIN 帳號，所以一定要先登入 SOMIN。

  2. 2

    上傳外掛程式

    開啟 Customize › Plugins ↗

    點擊 Add › Upload plugin，並從下載資料夾選擇 marketing-mondays.plugin。它會出現在您的外掛程式清單中，且已啟用。不需要另外下載技能庫：外掛程式已包含全部 26 項技能。

    還沒下載嗎？請先取得外掛程式。

  3. 3

    從外掛程式頁面連接 SOMIN

    上傳外掛程式並不會讓您登入任何服務。請在 Customize › Plugins 中開啟 Marketing Mondays，並選擇 Connectors 分頁。SOMIN 會顯示以下三種狀態之一：

    • Not added（未新增）：點擊 Add，再點擊 Connect。
    • Not connected（未連接）：點擊 Connect。
    • Connected（已連接）：大功告成。

    點擊 Connect 會立即連結到您已登入的 SOMIN 帳號，沒有額外的核准畫面。若您使用 Team 或 Enterprise 方案且無法自行新增，請洽您的 Claude Owner 新增 SOMIN 連接器，再以您自己的帳號連接。

  4. 4

    確認運作正常，然後產出您的第一份簡報

    詢問 Claude 能看到哪些 SOMIN 工作區 ↗。若幾秒內出現工作區名稱清單，就表示已連接成功。

    接著試試完整的工作流程。開啟已填入此提示詞的 Claude ↗，在 Claude 詢問時選擇工作區與品牌，然後看它建立簡報：

    我已連接 SOMIN MCP。請列出我可以使用的工作區；我選定後，請列出該工作區中可用的品牌；我選定品牌後，請為它建立一份 12 個月的策略簡報。完整分析請使用 /somin-brand-deck，SOMIN 樣式請使用 /somin-brand-guideline。請從 /scope-elicitation 開始。

    您也可以在訊息框中輸入 /：選單會列出每項技能及其所屬的外掛程式。

沒有 Connectors 分頁，或無法從那裡連接 SOMIN？請改以自訂連接器新增 SOMIN

此方式用來取代步驟 3，而非同時使用：兩個 SOMIN 連線會讓 Claude 擁有重複的工具。

開啟已預先填寫的「Add custom connector」對話框 ↗

或手動操作：在 Claude 中開啟 Customize › Connectors › Add custom connector。填寫兩個欄位，Advanced settings 下的 OAuth 欄位保持空白，然後點擊 Add。接著在標示為 CUSTOM 的 SOMIN 項目上點擊 Connect。

名稱SOMIN
伺服器 URLhttps://cloud.somin.ai/_mcp請保留底線：是 /_mcp，不是 /mcp。

使用預填連結時，出現粉紅色的「由外部連結建議」通知是正常的。確認名稱與 URL 後，點擊 Add。

遇到問題？

  • 沒有「Upload plugin」選項：您的組織會控管成員可新增哪些外掛程式。請洽您的 Claude Owner 開放權限，或請對方替您新增外掛程式。
  • SOMIN 顯示「Not added」且您無法新增：在 Team 與 Enterprise 方案中，連接器由 Owner 新增。請洽詢對方，或使用上方的自訂連接器方式。
  • 連接到錯誤的 SOMIN 帳號：請在 cloud.somin.ai 登出後重新登入，再從外掛程式的 Connectors 分頁中斷並重新連接 SOMIN。
  • Claude 沒有使用這些技能：請在 Customize › Plugins 中開啟外掛程式，確認其開關已啟用。

SOMIN 連線的更多細節：SOMIN 的 Claude 連線手冊 ↗（可略過其中的技能庫步驟：外掛程式已包含這些技能）。如有疑問：ask@mondays.marketing。

在 Claude Code 中：在 Claude 應用程式中新增的外掛程式，會同步到以同一帳號登入的 Claude Code；請執行 /reload-plugins。或執行 claude --plugin-dir ./marketing-mondays.zip 以在單一工作階段中使用。接著執行 /mcp，選擇 SOMIN 並登入。技能會以 /marketing-mondays:<skill> 的形式出現。

常見問題解答

什麼是 Marketing Mondays 外掛程式？

這是一款免費的 Claude 外掛程式，打包了 2026 年 10 月 12 日於 Marketing Mondays 現場展示的代理式行銷工作流程。其中八項主要技能與 18 項輔助技能可聆聽您的市場、解讀受眾與競爭對手、判斷市場空白、製作簡報、提案資料與創意素材，並交付內容行事曆，全部使用您的 SOMIN 數據。

使用它需要什麼？

支援外掛程式的 Claude：Claude 桌面應用程式、claude.ai 或 Claude Code。您還需要一個 SOMIN 帳號，因為每項技能都透過 SOMIN 連接器讀取您自己的數據。Figma 與 Postly 連接器為選用，用於製作與發布步驟。

需要付費嗎？

外掛程式可免費下載。它在您自己的 Claude 方案與 SOMIN 帳號中執行。

可以在 Claude Code 中使用嗎？

可以。請在 Claude 應用程式中安裝，並在以同一帳號登入的 Claude Code 中執行 /reload-plugins；或搭配下載的 .zip 執行 claude --plugin-dir，在單一工作階段中使用。技能會以 /marketing-mondays:<skill> 的形式出現。

我的數據會流向哪裡？

技能會讀取您的 SOMIN 工作區，並將報告、簡報與草稿交還給您。技能內的範例均為虛構，因此您的產出只會使用您自己的數據。您在下載表單中提供的資料，會提供給 Marketing Mondays 的技術夥伴 SOMIN。

如何取得協助？
