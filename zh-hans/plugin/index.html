设置 · 约三分钟

四步安装插件

一个文件包含全部内容：26 项技能，以及它们用来读取您数据的 SOMIN 连接器。您需要 Claude（桌面应用或 claude.ai）和一个 SOMIN 账户；Figma 和 Postly 为可选项。

  1. 1

    登录：先 SOMIN，后 Claude

    在 cloud.somin.ai 用希望 Claude 能看到其工作区的账户登录。然后打开 claude.ai 或 Claude 桌面应用。

    黄金法则：点击 Connect 时，Claude 会关联当前已登录的 SOMIN 账户，所以务必先登录 SOMIN。

  2. 2

    上传插件

    打开 Customize › Plugins ↗

    点击 Add › Upload plugin，从“下载”文件夹中选择 marketing-mondays.plugin。它会出现在您的插件列表中，并已开启。无需另外下载技能库：插件已包含全部 26 项技能。

    还没下载？请先获取插件。

  3. 3

    在插件页面连接 SOMIN

    上传插件并不会让您登录任何服务。在 Customize › Plugins 中打开 Marketing Mondays，选择其 Connectors 标签页。SOMIN 会显示以下三种状态之一：

    • 未添加（Not added）：点击 Add，然后点击 Connect。
    • 未连接（Not connected）：点击 Connect。
    • 已连接（Connected）：设置完成。

    点击 Connect 会立即关联您已登录的 SOMIN 账户，没有额外的授权页面。如果您使用 Team 或 Enterprise 方案且无法自行添加，请让您的 Claude Owner 添加 SOMIN 连接器，然后用您自己的账户连接。

  4. 4

    确认可用，然后生成您的第一份演示文稿

    问问 Claude 它能看到哪些 SOMIN 工作区 ↗。几秒内出现工作区名称列表，就说明已连接成功。

    然后试试完整工作流。打开已填好此提示词的 Claude ↗，在 Claude 询问时选择一个工作区和一个品牌，然后看它构建演示文稿：

    我已连接 SOMIN MCP。请列出我可以使用的工作区；我选择后，列出该工作区中可用的品牌；我选择品牌后，为所选品牌构建一份 12 个月的策略演示文稿。使用 /somin-brand-deck 进行完整分析，使用 /somin-brand-guideline 应用 SOMIN 样式。从 /scope-elicitation 开始。

    您也可以在消息框中输入 /：菜单会列出每项技能及其所属插件。

没有 Connectors 标签页，或无法从那里连接 SOMIN？请改为将 SOMIN 添加为自定义连接器

此方法用于替代第 3 步，而不是同时使用：两个 SOMIN 连接会让 Claude 拥有两套相同的工具。

或手动操作：在 Claude 中打开 Customize › Connectors › Add custom connector。填写两个字段，将 Advanced settings 下的 OAuth 字段留空，然后点击 Add。接着在标有 CUSTOM 的 SOMIN 条目上点击 Connect。

遇到问题？

  • 没有“Upload plugin”选项：您的组织控制成员可以添加哪些插件。请让您的 Claude Owner 开放权限，或代您添加插件。
  • SOMIN 显示“Not added”且您无法添加：在 Team 和 Enterprise 方案中由 Owner 添加连接器。请联系他们，或使用上面的自定义连接器方法。
  • 连接了错误的 SOMIN 账户：在 cloud.somin.ai 退出并重新登录，然后在插件的 Connectors 标签页中断开并重新连接 SOMIN。
  • Claude 没有使用这些技能：在 Customize › Plugins 中打开插件，检查其开关是否已打开。

常见问题解答

什么是 Marketing Mondays 插件？

一款免费的 Claude 插件，打包了 2026 年 10 月 12 日 Marketing Mondays 现场展示的智能体营销工作流。其八项核心技能和 18 项辅助技能可以聆听您的市场、解读受众与竞争对手、确定市场空白、制作简报、演示文稿和创意，并交付内容日历，全部基于您的 SOMIN 数据。

使用它需要什么？

支持插件的 Claude：Claude 桌面应用、claude.ai 或 Claude Code。您还需要一个 SOMIN 账户，因为每项技能都通过 SOMIN 连接器读取您自己的数据。Figma 和 Postly 连接器为可选项，用于制作和发布步骤。

需要付费吗？

插件可免费下载。它在您自己的 Claude 方案和您自己的 SOMIN 账户上运行。

可以在 Claude Code 中使用吗？

可以。在 Claude 应用中安装后，在登录同一账户的 Claude Code 中运行 /reload-plugins；或者用下载的 .zip 运行 claude --plugin-dir，在单次会话中使用。技能显示为 /marketing-mondays:<skill>。

我的数据会去哪里？

这些技能从您的 SOMIN 工作区读取数据，并把报告、演示文稿和草稿交还给您。技能中的示例均为虚构，因此您的产出只使用您自己的数据。您在下载表单中填写的信息将提交给 Marketing Mondays 的技术合作伙伴 SOMIN。
