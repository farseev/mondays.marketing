ติดตั้งปลั๊กอินในสี่ขั้นตอน

ไฟล์เดียวมีครบทุกอย่าง: 26 สกิล และคอนเน็กเตอร์ SOMIN ที่สกิลใช้อ่านข้อมูลของคุณ คุณต้องมี Claude (แอปเดสก์ท็อปหรือ claude.ai) และบัญชี SOMIN ส่วน Figma และ Postly เป็นตัวเลือกเสริม

  1. 1

    ลงชื่อเข้าใช้: SOMIN ก่อน แล้วจึง Claude

    ลงชื่อเข้าใช้ที่ cloud.somin.ai ด้วยบัญชีที่มีเวิร์กสเปซที่ Claude ควรเห็น จากนั้นเปิด claude.ai หรือแอปเดสก์ท็อป Claude

    กฎทอง: Claude จะเชื่อมกับบัญชี SOMIN ใดก็ตามที่ลงชื่อเข้าใช้อยู่ตอนที่คุณคลิก Connect ดังนั้น SOMIN ต้องมาก่อนเสมอ

  2. 2

    อัปโหลดปลั๊กอิน

    เปิด Customize › Plugins ↗

    คลิก Add › Upload plugin แล้วเลือก marketing-mondays.plugin จากโฟลเดอร์ Downloads ปลั๊กอินจะปรากฏในรายการปลั๊กอินของคุณโดยเปิดใช้งานอยู่ ไม่ต้องดาวน์โหลดคลังสกิลแยกต่างหาก เพราะปลั๊กอินมีครบทั้ง 26 สกิลแล้ว

    ยังไม่ได้ดาวน์โหลดใช่ไหม? รับปลั๊กอินก่อน

  3. 3

    เชื่อมต่อ SOMIN จากหน้าของปลั๊กอิน

    การอัปโหลดปลั๊กอินไม่ได้ทำให้คุณลงชื่อเข้าใช้สิ่งใด เปิด Marketing Mondays ใน Customize › Plugins แล้วเลือกแท็บ Connectors SOMIN จะแสดงสถานะใดสถานะหนึ่งจากสามแบบ:

    • Not added: คลิก Add แล้วคลิก Connect
    • Not connected: คลิก Connect
    • Connected: เสร็จเรียบร้อย

    Connect จะเชื่อมกับบัญชี SOMIN ที่ลงชื่อเข้าใช้อยู่ทันที ไม่มีหน้าจออนุมัติเพิ่มเติม สำหรับแพ็กเกจ Team หรือ Enterprise หากคุณเพิ่มเองไม่ได้ ให้ขอ Claude Owner ขององค์กรเพิ่มคอนเน็กเตอร์ SOMIN แล้วเชื่อมต่อด้วยบัญชีของคุณเอง

  4. 4

    ตรวจสอบว่าใช้งานได้ แล้วสร้างเด็คแรกของคุณ

    ถาม Claude ว่าเห็นเวิร์กสเปซ SOMIN ใดบ้าง ↗ หากได้รายชื่อเวิร์กสเปซภายในไม่กี่วินาที แสดงว่าเชื่อมต่อแล้ว

    จากนั้นลองเวิร์กโฟลว์เต็มรูปแบบ เปิด Claude พร้อมพรอมต์นี้ที่กรอกไว้แล้ว ↗ เลือกเวิร์กสเปซและแบรนด์เมื่อ Claude ถาม แล้วดูมันสร้างเด็ค:

    ฉันเชื่อมต่อ SOMIN MCP แล้ว ขอรายชื่อเวิร์กสเปซที่ฉันใช้งานได้ เมื่อฉันเลือกแล้ว ขอรายชื่อแบรนด์ที่มีในเวิร์กสเปซของฉัน เมื่อฉันเลือกแบรนด์แล้ว ให้สร้างเด็คกลยุทธ์ 12 เดือนสำหรับแบรนด์ที่ฉันเลือก ใช้ /somin-brand-deck สำหรับการวิเคราะห์เต็มรูปแบบ และ /somin-brand-guideline สำหรับสไตล์ของ SOMIN เริ่มต้นด้วย /scope-elicitation

    คุณยังพิมพ์ / ในช่องข้อความได้ด้วย เมนูจะแสดงทุกสกิลพร้อมปลั๊กอินที่มา

ไม่มีแท็บ Connectors หรือ SOMIN เชื่อมต่อจากแท็บนั้นไม่ได้? ให้เพิ่ม SOMIN เป็นคอนเน็กเตอร์แบบกำหนดเองแทน

ใช้วิธีนี้แทนขั้นตอนที่ 3 ไม่ใช่ทำทั้งสองอย่าง เพราะการเชื่อมต่อ SOMIN สองครั้งจะทำให้ Claude มีเครื่องมือชุดเดียวกันซ้ำสองชุด

เปิดหน้าต่าง “Add custom connector” ที่กรอกไว้แล้ว ↗

หรือทำด้วยตนเอง: ใน Claude เปิด Customize › Connectors › Add custom connector กรอกสองช่อง เว้นช่อง OAuth ใต้ Advanced settings ว่างไว้ แล้วคลิก Add จากนั้นคลิก Connect ที่รายการ SOMIN ที่มีป้าย CUSTOM

ชื่อSOMIN
URL ของเซิร์ฟเวอร์https://cloud.somin.ai/_mcpคงเครื่องหมายขีดล่างไว้: /_mcp ไม่ใช่ /mcp

ข้อความสีชมพู “suggested by an external link” เป็นเรื่องปกติเมื่อใช้ลิงก์ที่กรอกไว้แล้ว ตรวจสอบชื่อและ URL แล้วคลิก Add

ติดปัญหา?

  • ไม่มีตัวเลือก “Upload plugin”: องค์กรของคุณเป็นผู้กำหนดว่าสมาชิกเพิ่มปลั๊กอินใดได้บ้าง ขอให้ Claude Owner อนุญาต หรือเพิ่มปลั๊กอินให้คุณ
  • SOMIN แสดง “Not added” และคุณเพิ่มไม่ได้: ในแพ็กเกจ Team และ Enterprise ผู้ที่เป็น Owner เป็นผู้เพิ่มคอนเน็กเตอร์ ติดต่อผู้นั้น หรือใช้วิธีคอนเน็กเตอร์แบบกำหนดเองด้านบน
  • เชื่อมต่อบัญชี SOMIN ผิดบัญชี: ออกจากระบบแล้วลงชื่อเข้าใช้ใหม่ที่ cloud.somin.ai จากนั้นยกเลิกการเชื่อมต่อและเชื่อมต่อ SOMIN อีกครั้งจากแท็บ Connectors ของปลั๊กอิน
  • Claude ไม่ใช้สกิล: เปิดปลั๊กอินใน Customize › Plugins แล้วตรวจสอบว่าสวิตช์เปิดอยู่

รายละเอียดเพิ่มเติมเกี่ยวกับการเชื่อมต่อ SOMIN: คู่มือการเชื่อมต่อ Claude ↗ ของ SOMIN (ข้ามขั้นตอนคลังสกิล เพราะปลั๊กอินมีสกิลอยู่แล้ว) มีคำถาม: ask@mondays.marketing

ใน Claude Code: ปลั๊กอินที่เพิ่มในแอป Claude จะซิงก์ไปยัง Claude Code ที่ลงชื่อเข้าใช้ด้วยบัญชีเดียวกัน ให้รัน /reload-plugins หรือรัน claude --plugin-dir ./marketing-mondays.zip สำหรับหนึ่งเซสชัน จากนั้นรัน /mcp เลือก SOMIN แล้วลงชื่อเข้าใช้ สกิลจะปรากฏเป็น /marketing-mondays:<skill>

ปลั๊กอินฟรีสำหรับ Claude ที่รวบรวมเวิร์กโฟลว์การตลาดแบบเอเจนต์ซึ่งนำเสนอใน Marketing Mondays เมื่อวันที่ 12 ตุลาคม 2026 แปดสกิลหลักและ 18 สกิลผู้ช่วยจะรับฟังตลาดของคุณ ถอดรหัสกลุ่มเป้าหมายและคู่แข่ง ตัดสินใจเรื่องช่องว่างทางการตลาด สร้างบรีฟ เด็ค และครีเอทีฟ และส่งมอบปฏิทินคอนเทนต์ ทั้งหมดจากข้อมูล SOMIN ของคุณ

ต้องมีอะไรบ้างจึงจะใช้งานได้?

Claude ที่รองรับปลั๊กอิน: แอปเดสก์ท็อป Claude, claude.ai หรือ Claude Code และคุณต้องมีบัญชี SOMIN เพราะทุกสกิลอ่านข้อมูลของคุณเองผ่านคอนเน็กเตอร์ SOMIN ส่วนคอนเน็กเตอร์ Figma และ Postly เป็นตัวเลือกเสริมสำหรับขั้นตอนสร้างและส่งมอบ

มีค่าใช้จ่ายหรือไม่?

ปลั๊กอินดาวน์โหลดได้ฟรี โดยทำงานภายในแพ็กเกจ Claude ของคุณเองและบนบัญชี SOMIN ของคุณเอง

ใช้ใน Claude Code ได้หรือไม่?

ได้ ติดตั้งในแอป Claude แล้วรัน /reload-plugins ใน Claude Code ที่ลงชื่อเข้าใช้ด้วยบัญชีเดียวกัน หรือรัน claude --plugin-dir กับไฟล์ .zip ที่ดาวน์โหลดมาสำหรับหนึ่งเซสชัน สกิลจะปรากฏเป็น /marketing-mondays:<skill>

ข้อมูลของฉันไปที่ไหน?

สกิลจะอ่านข้อมูลจากเวิร์กสเปซ SOMIN ของคุณ แล้วส่งรายงาน เด็ค และฉบับร่างกลับมาให้คุณ ตัวอย่างในสกิลเป็นเรื่องสมมติ ผลลัพธ์ของคุณจึงใช้เฉพาะข้อมูลของคุณ ข้อมูลที่คุณกรอกในแบบฟอร์มดาวน์โหลดจะส่งไปยัง SOMIN พาร์ทเนอร์ด้านเทคโนโลยีของ Marketing Mondays

จะขอความช่วยเหลือได้อย่างไร?

เขียนถึง ask@mondays.marketing หรือนำคำถามของคุณมาที่ห้อง Marketing Mondays ครั้งถัดไปในสิงคโปร์
